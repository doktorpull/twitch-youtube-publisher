# Пошаговая настройка Personal Access Token (PAT)

## Шаг 1: Вход в GitHub

1. Откройте браузер и перейдите на https://github.com
2. Войдите в свой аккаунт (если еще не вошли)

## Шаг 2: Переход в настройки токенов

1. Нажмите на ваш аватар в правом верхнем углу
2. Выберите "Settings" (Настройки)
3. В левом меню прокрутите вниз и выберите "Developer settings" (Настройки разработчика)
4. Выберите "Personal access tokens" → "Tokens (classic)"

## Шаг 3: Создание нового токена

1. Нажмите кнопку "Generate new token" → "Generate new token (classic)"
2. Введите описание токена: "Twitch YouTube Publisher"
3. Выберите срок действия (Expiration):
   - Рекомендуется: 90 дней
   - Максимально: 1 год

## Шаг 4: Настройка разрешений (Scopes)

Выберите следующие разрешения (галочки):

### Обязательные разрешения:
- ✅ **repo** - Полный доступ к репозиториям
  - `repo:status` - Читать и изменять статус коммитов
  - `repo:deployment` - Управление развертываниями
  - `repo:contents` - Читать и записывать содержимое репозиториев
  - `repo:pull_request` - Читать запросы на слияние

### Опциональные (если планируете использовать):
- ✅ **workflow** - Доступ к GitHub Actions
- ✅ **read:packages** - Чтение пакетов
- ✅ **write:packages** - Запись пакетов

## Шаг 5: Генерация токена

1. Прокрутите вниз и нажмите "Generate token"
2. **Скопируйте токен сразу!** Он будет показан только один раз

## Шаг 6: Сохранение токена

1. Создайте безопасное место для хранения токена:
   - Рекомендуется: менеджер паролей (Bitwarden, 1Password)
   - Альтернатива: зашифрованный файл или заметка

## Шаг 7: Настройка репозитория

После получения токена настройте доступ к вашему репозиторию:

```bash
# В директории проекта
cd /var/www/twitch-yt

# Настройка удаленного репозитория с токеном
git remote set-url origin https://doktorpull:YOUR_TOKEN@github.com/doktorpull/dokcode.git

# Проверка настройки
git remote -v
```

## Важные замечания:

### Безопасность:
- Никогда не публикуйте токен в коде
- Не передавайте токен третьим лицам
- Регулярно обновляйте токен (каждые 90 дней)

### Если токен скомпрометирован:
1. Немедленно отзовите токен в GitHub settings
2. Создайте новый токен
3. Обновите настройки в проекте

### Альтернативные способы аутентификации:
1. **SSH ключи** - более безопасный вариант
2. **GitHub App** - для организаций

## Проверка работы токена:

```bash
# Попробуйте сделать пуш
git push -u origin main

# Если все настроено правильно - запросит пароль для doktorpull
# Введите ваш PAT как пароль
```

После настройки токена ваш проект будет готов к автоматической публикации!
